# V6 模型契约与实施边界

状态：`refactor/v6-row-aware-bay-zones` 的模型重构契约。V5 结果仅作历史记录，不能与 V6 直接比较。

## 1. 固定业务语义

### 1.1 出口箱组

一个出口箱组唯一对应：

`航次 + 尺寸 + 箱高 + 卸货港`

规划对象仅包括尚未进场的出口箱（`OF`）。相同四元组的需求必须在进入优化器前聚合；不同四元组必须是不同箱组。该定义不是运行时可配置项。

### 1.2 贝位与排

- 一个物理排资源由 `(bay_key, row_no)` 唯一标识。
- 不同出口箱组不可使用同一物理排；同一箱组可以使用该排的部分或全部剩余容量。
- 同一贝位可以被多个出口箱组使用，但它们必须使用不同物理排，并且整个贝位的新分配满足同一尺寸、同一箱高状态。
- 40/45 英尺箱同时占用其完整贝位 footprint 中的对应物理排资源。
- 已有箱形成的尺寸、箱高、航次和卸货港状态仍用于筛除不兼容候选。

由于箱组身份已经包含尺寸、箱高、航次和卸货港，“贝位尺寸/箱高一致 + 排航次/卸货港一致”等价推出“不同箱组不可共排”。V6 主模型使用直接的箱组—物理排 owner 约束表达该结论，属性状态只负责贝位兼容以及与已有箱状态兼容，不再用多个属性约束间接代表新箱组排独占。

### 1.3 Zone

一个 zone 是：

`一个箱组 + 一个箱区 + 一段连续锚定贝位 + 每个贝位中选取的非空排资源集合`

- 连续性只定义在贝位轴上，不定义在排号上。
- 相邻贝位选择的排号可以不同。
- 一个贝位可以为同一 zone 提供多个排。
- zone 的容量等于其所含原子排容量之和。
- 参考枚举暂保留“箱组需求量 + 一个最大原子排容量”的 zone 容量上限；该上限之后必须通过消融确认，而不能被当作业务硬约束。

候选 zone 之间允许重复包含贝位和物理排，因为它们只是备选方案。最终解中：

- 任一物理排最多归属一个箱组；
- 不同箱组可在尺寸、箱高兼容时，通过不同排共享一个贝位；
- 同一箱组的两个被选 zone 不得在贝位轴上重叠，邻接区间应合并为一个 zone。

### 1.4 匿名进口预留

进口箱仍按 `流向 + 尺寸` 聚合，只决定贝位级匿名容量，不分配航次、卸货港、箱高、箱组或具体排。

匿名进口预留必须满足：

- 箱区功能兼容；
- 20/40 英尺 footprint 和剩余物理容量；
- 同一进口预留贝位只能激活一个进口尺寸状态；
- 进口尺寸与已有贝位尺寸状态一致；
- 新进口预留与新出口分配不可使用同一物理贝位，包括 40 英尺 footprint 的两个成员贝位；
- 进口不参与出口的集中度、距离和排层面目标。

这里的“匿名”仅表示不做进口箱组和排级落位，不表示可以绕过贝位尺寸或进出口互斥约束。

## 2. 本轮实施边界

本轮只建立 V6 的正确性基础：

1. 固定箱组身份，并在输入边界验证聚合唯一性和排独占推论。
2. 在完整 row-location 参考 MIP 中使用直接的箱组—物理排 owner 约束。
3. 补齐匿名进口的尺寸状态、已有尺寸兼容和进出口贝位互斥。
4. 新建 row-aware zone 数据结构和小规模完整枚举器，作为后续定价与主问题的 oracle。
5. 用单元测试验证跨贝位可换排、同贝位不同排可供不同箱组、物理排不可跨箱组复用和进口规则。

本轮不做：

- 把 V5 固定排长条 pricing 改名后继续使用；
- 迁移 V5 static primal pool、multi-start、F&O、adaptive expansion 或 Local Branching；
- 修改目标权重或用过渡模型生成论文对比结果；
- 实现 V6 的高效 pricing、正式 restricted master、完整枚举 MIP 对照或大规模实验。

`preexperiment` 的 schema 和 V5 `ALGORITHM_VERSION` 在 V6 主从问题通过小算例等价性验证之前保持不变，防止历史结果与新模型混用。

## 3. 下一阶段准入条件

只有满足以下条件后才迁移算法组件：

1. V6 完整枚举 zone MIP 与 V6 restricted master 在小算例上目标值和可行性一致；
2. V6 pricing 能生成“贝位连续、排号可变、每贝至少一排”的负 reduced-cost zone；
3. 输出验证器能独立检查物理排 owner、贝位尺寸/箱高、进出口互斥和同组 zone 贝位不重叠；
4. 完整 MIP 与论文算法使用完全相同的 V6 目标定义和时间口径。

之后才评估哪些 V5 primal 组件值得按新资源冲突图重新实现；不能直接复用旧 strip 假设下的候选池和邻域。
