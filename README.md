# 出口资料箱排级堆场分配模型

本分支面向 TRE 论文场景。详细决策只针对已申报但尚未入场的出口资料箱；进口航次仅形成聚合容量预留，不参与具体贝位或排分配；出口预测量既不分配也不预留。

大计划长表只读取 `new_qty`：进口 `new_qty` 用于容量预留，出口 `new_qty` 归一化为资料箱的箱区比例参考。`planned_qty` 包含在场箱，不能作为本模型的新增需求或预留量。大计划箱型必须明确为 `20` 或 `40`，其中 `40` 包含真实 40 英尺和 45 英尺箱；`ALL`、空值、`45` 和其他未知值直接触发输入错误。

模型采用两个词典序阶段：先最小化未分配资料箱，再固定该最小值，优化大计划转移箱量、箱组箱区分散、箱组排分散、已有同类箱邻近、按箱量加权的泊位距离和大箱配对容量损失。进口大箱预留与大箱配对损失共享同一配对状态。

算法在明确声明的有限排模式空间上进行两阶段严格约化成本定价。每一阶段都检查全部未激活模式，只有不存在负约化成本模式时才结束；未完成收敛证明会直接报错。最终两阶段 MIP 使用完整有限模式集合，因此其 gap 对该有限模式模型有效。

45 英尺箱只能分配到箱区首尾可用的边缘大贝，并继续满足大贝配对、容量、排、尺寸、箱高、航次和目的港等普适约束。其他尺寸不会因为箱区中安排了 45 英尺箱而被施加箱区级边缘互斥。

详细数学边界见 [MODEL_SCOPE.md](MODEL_SCOPE.md)。

## 运行

```bash
python -m pip install -r requirements.txt
python -X utf8 -B run_medium_small.py --run-name example_full
```

默认使用 Gurobi。Gurobi 失败时程序直接报错，不会静默回退；只有显式传入 `--no-gurobi` 时才运行内置贪心方案。

主要输出：

- `export_row_plan.csv`：出口资料箱排级分配结果；
- `area_bay_summary.csv`：由排级结果聚合的箱区—贝位汇总；
- `declared_export_demand.csv`：出口资料箱需求；
- `unplaced_boxes.csv`：未分配量；
- `generated_columns.csv`：有限排模式列；
- `diagnostics.json`、`run_summary.json`：求解状态和独立一致性验证结果。
