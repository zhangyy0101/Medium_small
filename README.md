# 出口资料箱排级堆场分配模型

本分支面向 TRE 论文场景。详细排级决策只针对已申报但尚未入场的出口资料箱；进口航次只形成匿名的贝位—尺寸容量预留，不进行箱组、单箱或排级分配；出口预测量既不分配也不预留。

大计划长表只读取 `new_qty`：进口 `new_qty` 按 `flow×尺寸` 保持总量，并以原箱区分布作为软参考；模型可在功能兼容且尺寸容量可用的箱区之间做最小偏差调整。出口 `new_qty` 则归一化为资料箱的箱区比例参考。`planned_qty` 包含在场箱，不能作为本模型的新增需求或预留量。大计划箱型必须明确为 `20` 或 `40`，其中 `40` 包含真实 40 英尺和 45 英尺箱；`ALL`、空值、`45` 和其他未知值直接触发输入错误。

模型采用两个词典序阶段：先最小化未分配资料箱，再以等式固定该最小值，优化大计划转移箱量、箱组箱区分散、箱组排分散、已有同类箱邻近和按箱量加权的泊位距离。第二阶段未分配变量的目标系数为零，不再叠加百万惩罚。大计划偏差同时包含出口资料箱相对归一化箱区参考的偏差，以及进口匿名预留相对原大计划箱区分布的偏差。五项目标均按箱量、可行箱区/排或航次可行距离区间直接归一化。箱区分散、排分散、已有同类箱邻近、大计划偏差和泊位距离的经验权重依次为 `0.290/0.240/0.070/0.270/0.130`；前三项集中堆存与既有布局连续性合计为 `0.600`。该组权重根据归一化目标项的实际贡献和有效锚点覆盖率校准；已有同类箱邻近项仅覆盖少量资料箱，因而降低其权重，避免该局部目标主导总目标。没有任何可行同箱区位置的已有同类箱锚点保持目标中性，并从邻近项归一化分母中剔除，避免产生不影响决策的常数成本。箱组—箱区激活上界取相关需求与该箱组在该箱区的可行贝位—排容量之较小值，不再使用箱区无关总容量。大箱配对损失不再是目标。进口预留只满足箱区功能、贝位尺寸与联合物理容量：20英尺使用20英尺兼容贝位，40英尺大计划类别使用成对大贝足迹；进口预留不继承箱高、目的港、航次等混贝或混排规则。

每个列是一个出口箱组的完整排级布局模式：模式同时给出该箱组在多个箱区、贝位和排上的整数分配，以及可能保留的未分配量；模式内部直接满足尺寸、20/40/45英尺物理足迹、现有箱属性和自身排级容量，并准确计算该箱组的箱区及排分散成本。主问题为每个箱组选择一个模式，并统一处理共享贝位/排容量、跨箱组不混、进口匿名预留和大计划偏差。定价先使用稳定化对偶构造多种启发式模式；随后为每个箱组持久化一个定价 MIP，只更新目标系数并以该箱组的上一轮解作为 MIP start。普通轮只对仍活跃的箱组执行短时选择性定价，原始对偶认证轮则覆盖全部箱组。历史定价模式会按新对偶重新评估，新模式按负约化成本候选数自适应批量进入持久化受限主问题。

阶段一达到零未分配时，由目标非负性直接证明最优。阶段二定期使用原始对偶对全部箱组定价，并以各箱组最小约化成本下界之和修正受限主问题目标，形成全模式 LP 的有效下界：定价达到最优时使用最优约化成本，触及时限时使用 Gurobi 的严格目标下界，二者不会混同报告。默认在传统定义的相对 LP gap 不超过 `0.5%` 时终止，可通过 `--pattern-lp-gap` 调整；代码同时报告绝对 gap 和相对 gap，设为 `0` 要求下界证明不存在负约化成本模式。最终先求解整数模式主问题，再构造扩充位置池进行 fix-and-optimize：位置池除主问题已有模式外，还包含定价缓存模式，以及最终分数模式、整数 incumbent 和最近原始对偶负约化成本模式所支持箱组—箱区内的可行排位置。该过程不是 branch-and-price，也不宣称完整整数最优性，最终整数解相对模式 LP 下界的有效绝对/相对 gap 会单独报告。

45 英尺箱只能分配到箱区首尾可用的边缘大贝，并继续满足大贝配对、容量、排、尺寸、箱高、航次和目的港等普适约束。其他尺寸不会因为箱区中安排了 45 英尺箱而被施加箱区级边缘互斥。

详细数学边界见 [MODEL_SCOPE.md](MODEL_SCOPE.md)。

## 运行

```bash
python -m pip install -r requirements.txt
python -X utf8 -B run_yard_plan.py --run-name example_full
```

求解器固定使用 Gurobi；初始化、受限主问题、定价和最终整数主问题中的任何失败都会直接报错，不存在备用贪心求解路径。

大计划只提供软箱区参考，不能绕过箱区功能硬约束。固定实验线程数可使用 `--solver-threads`；自适应定价批量可使用 `--pricing-min-batch`、`--pricing-max-batch` 和 `--pricing-fraction` 调整；普通轮选择性定价与全组认证定价的时限分别由 `--selective-pricing-time-limit` 和 `--exact-pricing-time-limit` 控制；稳定化系数、原始对偶检查间隔和相对模式 LP gap 分别由 `--dual-stabilization-alpha`、`--raw-dual-check-interval` 和 `--pattern-lp-gap` 控制。

堆场快照预处理采用必要列的批量对象数组、单次容器索引和属性状态去重，不再按箱号或贝位反复切分完整 DataFrame。每次运行都会输出 `runtime_breakdown_seconds`，分别记录 JSON 读取、大计划读取、输入预处理、规划器初始化和优化求解耗时。

主要输出：

- `export_row_plan.csv`：出口资料箱排级分配结果；
- `import_capacity_reservation.csv`：按 `flow×尺寸×贝位` 输出的匿名进口容量预留，不是进口箱作业分配；
- `bay_summary.csv`：由排级结果聚合的箱区—贝位汇总；
- `declared_export_demand.csv`：出口资料箱需求；
- `unplaced_boxes.csv`：未分配量；
- `selected_row_locations.csv`：最终位置池重组所选中的排级位置及箱量；
- `diagnostics.json`、`run_summary.json`：求解状态、独立一致性验证结果，以及 JSON 读取、输入预处理、规划器初始化和优化求解的分段耗时。
- `output_validation.json`：仅根据模型输入和写出的 CSV，重新检查箱组身份、排级足迹、箱区功能、需求、容量、全部配置化不混属性、进口预留及 45 英尺规则。
