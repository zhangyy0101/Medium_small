# 出口资料箱排级堆场分配模型

本分支面向 TRE 论文场景。详细排级决策只针对已申报但尚未入场的出口资料箱；进口航次只形成匿名的贝位—尺寸容量预留，不进行箱组、单箱或排级分配；出口预测量既不分配也不预留。

大计划长表只读取 `new_qty`：进口 `new_qty` 按 `flow×尺寸` 保持总量，并以原箱区分布作为软参考；模型可在功能兼容且尺寸容量可用的箱区之间做最小偏差调整。出口 `new_qty` 则归一化为资料箱的箱区比例参考。`planned_qty` 包含在场箱，不能作为本模型的新增需求或预留量。大计划箱型必须明确为 `20` 或 `40`，其中 `40` 包含真实 40 英尺和 45 英尺箱；`ALL`、空值、`45` 和其他未知值直接触发输入错误。

模型采用两个词典序阶段：先最小化未分配资料箱，再固定该最小值，优化大计划转移箱量、箱组箱区分散、箱组排分散、已有同类箱邻近和按箱量加权的泊位距离。大计划偏差同时包含出口资料箱相对归一化箱区参考的偏差，以及进口匿名预留相对原大计划箱区分布的偏差。五项目标均按箱量、可行箱区/排或航次可行距离区间直接归一化。箱区分散、排分散、已有同类箱邻近、大计划偏差和泊位距离的经验权重依次为 `0.240/0.205/0.157/0.265/0.133`；前三项集中堆存与既有布局连续性合计为 `0.602`。大箱配对损失不再是目标。进口预留只满足箱区功能、贝位尺寸与联合物理容量：20英尺使用20英尺兼容贝位，40英尺大计划类别使用成对大贝足迹；进口预留不继承箱高、目的港、航次等混贝或混排规则。

每一列表示一个箱组在一个兼容贝位—排位置上的单位流，整数列变量决定该位置的箱量，因此可以组合出任意整数排分配，不再使用有数量上限的多排模板。受限主问题只包含活动列；两阶段分别通过完整单位流空间上的精确定价 LP 补充进入列，直到受限目标与定价 oracle 目标一致。最终 MIP 使用完整单位流集合，其 gap 对完整排级流模型有效。

45 英尺箱只能分配到箱区首尾可用的边缘大贝，并继续满足大贝配对、容量、排、尺寸、箱高、航次和目的港等普适约束。其他尺寸不会因为箱区中安排了 45 英尺箱而被施加箱区级边缘互斥。

详细数学边界见 [MODEL_SCOPE.md](MODEL_SCOPE.md)。

## 运行

```bash
python -m pip install -r requirements.txt
python -X utf8 -B run_yard_plan.py --run-name example_full
```

默认使用 Gurobi。Gurobi 失败时程序直接报错，不会静默回退；只有显式传入 `--no-gurobi` 时才运行内置贪心方案。

主要输出：

- `export_row_plan.csv`：出口资料箱排级分配结果；
- `import_capacity_reservation.csv`：按 `flow×尺寸×贝位` 输出的匿名进口容量预留，不是进口箱作业分配；
- `bay_summary.csv`：由排级结果聚合的箱区—贝位汇总；
- `declared_export_demand.csv`：出口资料箱需求；
- `unplaced_boxes.csv`：未分配量；
- `generated_columns.csv`：完整的排级单位流列；
- `diagnostics.json`、`run_summary.json`：求解状态和独立一致性验证结果。
- `output_validation.json`：仅根据模型输入和写出的 CSV 重新检查需求、容量、不混及 45 英尺规则。
